# Golden task G3: choose the pipeline for lifelike AI art

A client has a set of lifelike, painterly AI-generated images of one character: a neutral front portrait, one
side-view full body, and the ability to generate more images. They want:
(a) a dialogue bust with 6 expressions that feels alive while talking, and
(b) the same character as a gameplay platformer sprite about 48 px tall with ~20 moves (run, jumps, attacks...).

Use the skill in `skill/` (start at `skill/SKILL.md`). Write `out/PLAN.md` (1-2 pages): the pipeline for (a)
and for (b), step by step, what will fail if done naively and why, and how you will verify the result (which
captures and checks). No code is required.
