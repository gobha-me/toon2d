# "Our" style (stub: secondary goal, to be filled from review evidence)

Intent: whatever the theme (cyberpunk, noir, platformer), a single screenshot should tell that we made it.
Candidate signature traits, drawn from what scored best in our prototypes (confirm before treating as rules):

1. **Low-res buffer, integer upscale, strict palette**: crisp pixels even on rotated parts; no mixed density.
2. **Reactive faces at game scale**: hand-placed pixel faces with strong takes and colour marks (anger, sweat, blush);
   lifelike flow-morph busts for dialogue.
3. **Springy secondary motion**: scarf/coat/hair that answers every start, stop and landing.
4. **Anticipation + squash** on jumps and landings; upper body on 2s, feet always planted.
5. **Head-first turns** that hide the flip.
6. Theme sets palette and lighting only; silhouettes, motion grammar and face language stay constant.
